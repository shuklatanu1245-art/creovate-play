# 🔮 Crochit - Videos, Reels, Real-Time Chat & Profile

![Crochit Logo](assets/logo.png)

**Crochit** is an all-in-one platform featuring 4 core bottom navigation pages:
1. 🏠 **Home:** Full-length shows, tutorials, documentaries & podcasts (Native in-app player with infinite scrolling & real search).
2. ⚡ **Feed:** Fullscreen vertical snap-scroll reels with automatic playback & infinite scrolling.
3. 💬 **Chat:** Real-Time P2P WebRTC messaging with floating Picture-in-Picture mini-player & video attachments.
4. 👤 **Profile:** View account, in-place database updates for username & password (no duplicate accounts), and cloud database setup.

---

## 📱 4 Core Navigation Pages

### 1. 🏠 Home Page (Long Videos & Real Search)
- Only long-form videos (masterclasses, full podcasts, documentaries, lofi live streams).
- **100% Native In-App Playback:** Videos play directly inside the app with high-performance native players.
- **Real Search Button:** Search across video titles, topics, creators, and descriptions with instant results.
- **Infinite Scrolling:** Scroll down to load unlimited new videos automatically.
- **Float & Chat:** Minimize any video to a floating corner player so you can watch while chatting.

### 2. ⚡ Feed Page (Vertical Snap-Scroll Reels)
- True vertical snap-scrolling reels feed (swipe/scroll up to transition to the next reel).
- **Automatic Playback:** Active reel automatically plays when in view.
- **Interactive Controls:** Like (with heart animation), Comments, Share to Chat, Sound Mute/Unmute, and Float & Chat.
- **Infinite Reels:** Automatically loads more reels as you scroll so the stream never ends.

### 3. 💬 Chat Page (Real Persons & Floating PiP)
- WebRTC end-to-end direct messaging.
- Floating Mini-Player: Watch any video or reel in the corner without interrupting conversation.
- Attach any video or reel directly into the chat stream.

### 4. 👤 Profile Page (In-Place Database Update)
- View profile info, stats, joined date, and avatar.
- **In-Place DB Update:**
  - When changing **Username** or **Password**, the database updates the exact existing record by user ID — no duplicate accounts are created.
- **Database Connection Guide:**
  - Integrated Supabase cloud client for multi-user sign up and login online when deploying to Vercel.
