# 🔮 Crochit - Home, Feed, Chat & Profile

![Crochit Logo](assets/logo.png)

**Crochit** is a complete hybrid platform featuring 4 core bottom navigation pages:
1. 🏠 **Home:** YouTube Long Videos ONLY (10+ minutes, podcasts, masterclasses, in-app player with live search).
2. ⚡ **Feed:** Instagram Reels ONLY (vertical videos playing directly inside the app, + link any custom reel).
3. 💬 **Chat:** Real-Time P2P WebRTC Chat with floating Picture-in-Picture mini-player & video attachments.
4. 👤 **Profile:** View profile, in-place Username & Password database updates (no duplicate accounts), and cloud database setup.

---

## 📱 4 Core Navigation Pages

### 1. 🏠 Home Page (YouTube Long Videos Only)
- Only long-form videos (podcasts, full tutorials, documentaries, chill lofi streams).
- **100% In-App Playback:** YouTube open iframe player bina YouTube par redirect kiye app ke andar hi play karta hai.
- **Search Bar:** Real-time search by video title, channel, and tags.
- **Float & Chat:** Kisi bhi long video ko corner me minimize karke chat tab me le ja sakte hain!

### 2. ⚡ Feed Page (Instagram Reels Only)
- Pure vertical reel feed with creator tags and view counts.
- **+ Link Any Reel:** Instagram app ya browser se kisi bhi reel ka link paste karein aur instantly Crochit me dekhein.
- Direct share to chat button.

### 3. 💬 Chat Page (Real Persons & Floating PiP)
- WebRTC end-to-end direct messaging.
- Floating Mini-Player: Chahe YouTube long video ho ya Instagram reel, corner me chalti rahegi aur chat uninterrupted chalegi!

### 4. 👤 Profile Page & Database
- View account statistics, avatar, joined date, and email ID.
- **In-Place DB Update:**
  - Jab aap Username ya Password change karenge, toh **database me naya record nahi banega** — wahi existing account update hoga!
- **Database Kaise Connect Karein (Sign Up & Login Guide):**
  - **Supabase Cloud Database:**
    1. [supabase.com](https://supabase.com) par free project banayein.
    2. Settings -> API se **Project URL** aur **Anon Key** copy karein.
    3. Profile page me "Configure Keys" par click karke paste kar dein.
    4. Done! Puri duniya me koi bhi insaan aapki Vercel website par Sign Up aur Login kar sakega!
